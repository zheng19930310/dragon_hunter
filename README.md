# 降龙猎手 · 五行觉醒

> **本仓库借鉴游戏《降龙猎手》demo 构建**（原始项目：`gitee.com/mobuhan/dragon_hunter`），在其 V1.9.0 版本的基础上继续开发，并加入了一批不一样的元素——更凶的怪物 AI、有节气的天气、会挥砍扑咬的战斗动作、带障碍物的副本、背景音乐与音效控制等。完整改动记录见根目录各版本 `需求.md`。

## 立即开玩

**下载 `index.html`，双击即可运行。**

免安装、免联网、免服务器、无构建步骤——整个游戏就是这一个 HTML 文件（约 550KB / 6000 行），浏览器打开即是完整客户端。电脑用鼠标键盘，手机直接触屏，进度自动存在浏览器本地。

> 建议 Chrome / Edge / Safari 等现代浏览器。存档在浏览器本地，清缓存或换浏览器会丢进度，请留意。

## 这是什么

一款单文件 Canvas 2D 俯视角动作 RPG。你在落鸦村醒来，背着旧猎弓走进 10000×7500 的开放世界——35 个分区、34 种妖魔、五行装备、33 门技能，一路砍到天使形态觉醒。

没有剧情过场拖时间，反馈全在刀口上：数字飘字、爆装光柱、击杀祝福弹幕。

## 核心玩法

**世界与时辰**
十二时辰制实时流转，一个时辰 2 分钟。夜色渐深时怪物夜战加成最高 +50%，你的视野却收成一盏灯；晴、多云、落雨、雷暴、飘雪、大雾、疾风七种天气轮换（大雾只在晨昏出现），转换时屏幕给出 5 秒天象横幅。天气纯视觉不吃数值——但夜晚是真的难。

**战斗**
所有怪物主动索敌追击，近战扑咬、远程放风筝、精英与 BOSS 轮番施法，普通怪也有专属技能。五系武器（弓/剑/刀/枪/杖）各有独立攻击节奏、特效与 20 段进阶名，翻滚带无敌帧可穿墙越界。人怪都有起手动作：挥砍扫击、后坐、聚能光环，不是站着掉数字。

**成长**
装备品质七档（白→绿→蓝→紫→橙→红→金），每高一档多一条词条；五行词条 + 每怪专属套装 + 镶嵌孔。33 格技能树自由构筑，主动技能 4 栏装配，伴生技能靠使用次数升级。属性点自由分配，敏捷同时影响移速/攻速/暴击/闪避。

**副本（5 类）**
- ⛩ **幻境副本**——每种怪一座，50 小怪 + 精英环伺 + 1~3 BOSS，斩尽 BOSS 才开退路
- 🗼 **通天塔**——100 层，逐层变强，每清一层叠一重塔内增益（出塔即散），可传送已刷层
- 🌀 **万妖迷宫**——全 BOSS 长廊，杀一只余党全体涨 5%
- 🥚 **产蛋秘境**——四角守护兽，刷宠物蛋
- 🏇 **御骑境**——单挑坐骑 BOSS，赢了收骑

副本内随机布有石柱与木箱掩体，进出各有一次 3 秒「地图加载中」。

**其它**
11 匹坐骑、4 槽宠物孵化、怪物变身（可扮精英/BOSS）、成就里程碑解锁拍动光翼（10）→ 圣辉头环（15）→ 天使形态（30）、主线 20 章「劳务派遣」职场喜剧 + 全怪支线讨伐、48 条祝福弹幕词库、10 个本地存档位。

## 操作

| 键 | 功能 | 键 | 功能 |
|---|---|---|---|
| `WASD` / 方向键 | 移动 | `鼠标左键` | 攻击（朝准星） |
| `空格` | 翻滚（无敌帧） | `1`~`4` | 主动技能 |
| `E` | 交互 / 对话 | `5` | 变身 |
| `B` | 背包 | `T` | 怪物图鉴 |
| `C` | 技能搭配升级 | `H` | 人物面板 |
| `J` | 任务与成就 | `O` | 设置 |
| `F` | 回城 | `R` | 仓库（村内） |
| `Q` | 快捷药水 | `Esc` | 关闭所有面板 |

手机端为虚拟摇杆 + 放大攻击钮 + 底部技能栏，攻击可自动索敌。

## 设置项

按 `O` 打开设置：击杀播报分级（普通/精英/BOSS）、拾物播报、🎵 背景音乐开关与音量、音效音量、⚔ 攻击声效独立开关、祝福弹幕密度三档（稀疏/标准/狂热）。

## 技术说明

- 单文件，零依赖，零构建；逻辑分辨率 960×540，按 DPR 与窗口自适应缩放
- 60fps `requestAnimationFrame` 主循环 + 全局帧计数驱动所有动画与计时
- 空间哈希网格做碰撞分桶，怪物按玩家位置懒加载/卸载
- 音效与 BGM 由 Web Audio 振荡器实时合成，不含任何音频文件
- 存档走 `localStorage`，读档对旧档缺失字段自动回退默认值
